# 🧮 CJ Lajes – Calculadora de Vigas, Isopor e Custo (PWA)

Este é um **PWA (Progressive Web App)** simples e rápido para calcular:

- Área total em m²
- Quantidade de vigas
- Quantidade de isopor
- Valor total a cobrar

O objetivo é facilitar orçamentos de construção civil, especialmente para quem trabalha com **lajes treliçadas** e **vigas de isopor**.

O app funciona direto no navegador e pode ser instalado no celular como se fosse um aplicativo nativo.

## 🚀 Funcionalidades

✔ Cálculo automático baseado em largura × comprimento  
✔ Alternância entre métodos de cálculo (via largura ou via comprimento)  
✔ Cálculo de custo por metro  
✔ Interface simples e responsiva  
✔ Ícones e UI minimalista  
✔ Pode ser instalado como app (PWA)  
✔ Funciona offline após o primeiro acesso

## 🧩 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **PWA**
  - Manifest
  - Service Worker

## 📱 Como Usar

1. Preencha o **valor por metro** (ex: `35.00`)
2. Informe a **largura (L)**
3. Informe o **comprimento (C)**
4. Escolha o modo:
   - Cálculo com base na **largura**
   - Cálculo com base no **comprimento**
5. Clique em **Calcular**

O app exibirá:

- Área total (m²)
- Quantidade de vigas
- Quantidade de isopor
- Valor total a ser cobrado
